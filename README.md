## ??? Tech Stack & Architecture

* **Framework**: React 19 + TypeScript + Vite
* **Styling**: Tailwind CSS with custom golf-green color palettes (#062e1b, #072417, #10b981)
* **Icons**: Lucide React
* **Routing**: Hash-based Single Page Application (SPA) compatible with 100% static hosting (Cloudflare Pages, Vercel, AWS S3)
* **SEO**: Programmatic Schema.org JSON-LD (Product, Review, FAQPage)
